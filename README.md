
<h1 align="center">B14-A7-Bazar Dor</h1>

## 📌 Project Description

Bazar Dor is designed to make everyday market price information accessible. It displays product names, categories, current prices, units, and price changes to help users understand market trends.

## 🛠️ Technology Used

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **DaisyUI**
- **Git & GitHub**
- **Vercel**

## ✨ Features

### 1. Product Listing
Everyone can browse daily essential products in one place.

### 2. Product Categories
Explore products by category, such as rice, oil, vegetables, fish, and meat.

### 3. Product Details
Click on a product card to view details about the item.

### 4. Price Changes
Product price increases or decreases are displayed.

### 5. Responsive Design
Access the application on desktop, tablet, and mobile screens.
